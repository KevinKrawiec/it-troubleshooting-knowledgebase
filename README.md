ENG:

it-troubleshooting-knowledgebase is a console-based project that uses Python and JSON files as a simple IT troubleshooting knowledge base.

Each JSON file contains troubleshooting instructions for a specific area, for example:

- network.json contains steps for diagnosing and fixing common network and Internet connection problems.
- screen.json contains troubleshooting steps for monitor and display issues, such as a second monitor showing "No Signal".
- windows.json contains basic Windows troubleshooting and support knowledge.

The project will be expanded as I continue learning from the Cisco IT Support Specialist Career Path course.

The main goal of this project is to learn and practice basic Help Desk troubleshooting and to expand my knowledge in IT support. Python is used only as a simple tool to display and organize the troubleshooting knowledge.


PL:

it-troubleshooting-knowledgebase to konsolowy projekt wykorzystujący Python i pliki JSON jako prostą bazę wiedzy z zakresu rozwiązywania problemów IT.

Każdy plik JSON zawiera instrukcje dotyczące konkretnego obszaru, na przykład:

- network.json zawiera kroki diagnostyczne i rozwiązania typowych problemów z siecią oraz połączeniem internetowym.
- screen.json zawiera instrukcje dotyczące problemów z monitorem i obrazem, np. gdy drugi monitor pokazuje komunikat „No Signal”.
- windows.json zawiera podstawową wiedzę dotyczącą rozwiązywania problemów i obsługi systemu Windows.

Projekt będzie rozwijany wraz z moją dalszą nauką z kursu Cisco IT Support Specialist Career Path. W planach też zrobienie możliwości wybrania języka na polski.

Głównym celem projektu jest nauka i ćwiczenie podstaw troubleshootingu Help Desk oraz poszerzanie wiedzy z zakresu wsparcia IT. Python pełni tutaj jedynie rolę prostego narzędzia do wyświetlania i organizowania tej wiedzy.
